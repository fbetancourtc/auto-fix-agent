## Lessons Learned
- `use_external_ip: true` breaks Docker-internal clients (bots in HeadlessChrome on same host)
- LiveKit TURN TLS requires a cert file; use `tls_port: 0` to disable if no cert available
- TURN relay range defaults to 30000-40000; must expose in Docker
- Cloudflare Tunnel hairpin (host → CF → host) is unreliable for WebRTC signaling
- `MAX_USERS_FOR_WEBRTC` is critical: 0 = always LiveKit (bad for local bots), 4 = WebRTC for small groups
