## LiveKit Fix — RESOLVED (~17:45–18:10 UTC)

### Root cause: LiveKit SDK ignores URL path
- The LiveKit JS SDK **strips the path** from the host URL and only uses the origin
- `LIVEKIT_HOST=https://village.getdealflow.co/livekit` → SDK sends to `https://village.getdealflow.co/twirp/livekit.RoomService/...` (no `/livekit` prefix) → hits play container → 404
- Confirmed by intercepting SDK fetch: pathname was `/twirp/...` not `/livekit/twirp/...`

### Solution implemented
1. **nginx.conf** — Added `/twirp/` location block that proxies to `http://livekit:7880` (before the catch-all `/` block)
   - Play doesn't use `/twirp/` paths, so no collision
2. **LIVEKIT_HOST** kept as `https://village.getdealflow.co/livekit` in docker-compose
   - SDK Twirp API calls go to `/twirp/...` → nginx routes to LiveKit ✅
   - Frontend WSS URL: `.replace("http","ws")` → `wss://village.getdealflow.co/livekit` → nginx `/livekit` block handles WebSocket upgrade to LiveKit ✅
3. Restarted nginx + back containers
